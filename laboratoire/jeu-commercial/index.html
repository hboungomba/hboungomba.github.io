Accords commerciaux comme
mécanismes de dépendance
Cet outil accompagne le Tome 2 en permettant d'explorer interactivement les modèles formels développés dans les chapitres 1 à 7. Chaque module correspond à un mécanisme central du livre et peut être manipulé en temps réel pour observer les équilibres, les seuils critiques et les dynamiques d'accumulation.

Comment utiliser ce simulateur — Naviguez entre les modules via la barre latérale. Chaque module correspond aux chapitres indiqués. Manipulez les curseurs pour faire varier les paramètres : la matrice ou le graphique se recalcule en temps réel, et l'interprétation analytique identifie le régime théorique actif (équilibre coopératif, asymétrique, ou de verrouillage). Le bouton Approfondir ↗ en bas de chaque module renvoie vers le texte correspondant du Tome 2.
